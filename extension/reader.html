仿生 PDF 阅读指南

读自己的 PDF、试读示例，或为常用阅读器制作副本。按你现在想做的事查看步骤。

打开 PDF，切换词首加粗
  1. 在首页点「打开 PDF」，也可以直接拖入文件。
  2. 点「仿生」看词首，再点「原始」对照同一行。阅读时按 Alt+B 也能切换。
  3. 想微调时，在「阅读设置」中调整强度。窄窗口可先展开「阅读设置与目录」。英语可以从「英文词首规则」和 100% 强度开始。

第一次使用可以先点首页的「试读两页示例」。每页上方的小提示会带你练习切换、跟随引用和返回。

查找一句话，或从引用回到原段落

点「查找」，或按 Ctrl+F（Mac 用 ⌘F）。Enter 查找下一处，Shift+Enter 查找上一处。Esc 收起查找。跟随书内引用、目录或搜索结果后，点一次「返回原处」即可恢复之前的段落和缩放。网页引用在新标签页打开。

保留进度，或迁移到另一台电脑

更新 Chrome / Edge 时，把新版解压覆盖到原安装目录，再到扩展管理页点「重新加载」。换目录或电脑前，在首页展开「更新扩展或迁移阅读进度」导出备份，到新阅读器首页导入。旧版可以先在原目录升级。

安装阅读器，或从浏览器里的 PDF 打开

Chrome / Edge 使用 chrome-edge 压缩包。解压后在扩展管理页开启开发者模式，选择「加载已解压的扩展程序」，选含 manifest.json 的文件夹。在已打开的 PDF 标签页点扩展图标即可阅读。读取本地标签页需要在扩展详情中启用「允许访问文件网址」。临时链接可先保存再打开。

Windows 使用 windows-x64 压缩包，完整解压后运行 BionicPDF.exe。Firefox 可通过制作工具打开本地阅读页，也可加载临时扩展，重启后需重新加载。网页包需要通过本地网页服务打开。

只导出一页，或取消正在制作的副本

在 Windows 制作工具展开「页码、语言与扫描件」，在「导出页码」输入 1 即可先试做一页。导出中点「取消导出」，当前步骤结束后停止。可以调整范围后再试。

在 WPS / Acrobat / Foxit / PDF-XChange 原页开关
  1. 在 Windows 制作工具中选择原始 PDF，选择「可切换版」。
  2. 保存成不同文件名，再用你的 PDF 阅读器打开副本。
  3. 在「图层 / Layers」面板开关「仿生阅读 · Bionic Reading」。图层默认关闭。

WPS：左侧「图层」图标 → 眼睛开关。PDF-XChange：Ctrl+L 打开图层 → 点击灯泡。

Acrobat：菜单 → 视图 → 显示/隐藏 → 侧面板 → 图层。Foxit：在左侧导航栏空白处右键 → 图层，再勾选该图层。不同版本菜单名称可能不同。找不到图层入口时可改用普通仿生版。

Preview / SumatraPDF / 手机等阅读器

在 Windows 工具选择「普通仿生版」，生成后直接打开。该副本的加粗始终显示；切回原始效果请打开原文件。

支持哪些语言？如何配置？

英语、法语、德语、西班牙语、葡萄牙语、意大利语、荷兰语、波兰语、土耳其语、越南语、俄语、乌克兰语、希腊语。

浏览器阅读混合语言文档时可选「词语前半部分」。在 Windows 工具制作副本时，自动和英语对纯英文字母词应用参考规则。选择其他语言时，按完整字素加粗前半词。手动选择还会设置副本的文档语言，自动模式沿用原文件的语言标记。重音和连字按完整字素或原始字形处理。

双页讲义、扫描页或乱码怎么办？

双页讲义左右两半合计一页。制作工具的「导出页码」可填 1-3,7,5-4，留空导出整本。完成后可查看未加粗的副本页码。讲义自带的翻页按钮也能在阅读页使用。

若正文无法选中，或只能选中标题、页码和零散的词，在 Windows 制作工具展开「页码、语言与扫描件」，勾选「扫描页本地 OCR」，选择文档语言并生成「可切换版」。先装好本机 Tesseract 5 和相应语言包。打开副本，点「查找」输入正文中的一句话。用「原始／仿生」切换时，识别出的文字始终可以搜索和复制。特殊字体和竖排文字可能保持原样。若出现乱码，先对照源 PDF。

English quick start

Choose 打开 PDF to open a file, or 试读两页示例 to try the two-page sample. Compare the same line using 原始 (original) and 仿生 (emphasis). Use Ctrl+F or ⌘F to search. After following a result or a citation, choose 返回原处 to return.

In the Windows maker, choose 可切换版 for switchable Layers or 普通仿生版 for always-visible emphasis. Open 页码、语言与扫描件 for page ranges, language and OCR. Choose 生成阅读副本 to export.
