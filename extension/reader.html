仿生 PDF 阅读指南

第一次使用可在阅读器首页点「试读两页示例」。试着切换词首加粗，点示例里的引用，再用「返回原处」回到起点。

English quick start

Choose 试读两页示例 for the two-page sample, or 打开 PDF for your own file. Select 仿生 to emphasize word beginnings and 原始 to see the original. Find text with Ctrl+F or ⌘F. After following a result or a citation, 返回原处 takes you back.

In the Windows maker select 可切换版 for a copy with a Layers switch, or 普通仿生版 for always-visible emphasis. 生成阅读副本 starts the export. 取消导出 stops it after the current step.

升级后怎样保留进度？

Chrome / Edge 请把新版解压覆盖到原文件夹，在扩展管理页点「重新加载」。换目录或电脑前，先在阅读器首页展开「更新扩展或迁移阅读进度」并导出备份，再到新阅读器首页导入。旧版没有导出按钮时，先在原目录升级。

第一次安装：下载哪个包？

Windows：下载 windows-x64 压缩包，完整解压后运行 BionicPDF.exe，无需安装 Python。Chrome / Edge：下载 chrome-edge 压缩包并解压，在 chrome://extensions 或 edge://extensions 开启开发者模式，选择「加载已解压的扩展程序」，选择含 manifest.json 的文件夹，再点击扩展图标。

Firefox 推荐通过 Windows 工具打开本地阅读页；另提供临时开发扩展，浏览器重启后会移除。网页包需要本地网页服务，请勿直接双击 reader.html。

在浏览器里直接切换
  1. 在 Chrome 或 Edge 已打开的 PDF 标签页点扩展图标，或点「打开 PDF」选择文件。打开本地标签页时，请先在扩展详情中启用「允许访问文件网址」。临时链接可先保存再打开。
  2. 在侧栏选择文档语言。窄窗口中先展开「阅读设置与目录」。英语可使用「参考项目规则」，其他语言推荐「词语前半部分」。
  3. 点击顶部「仿生」，或按 Alt+B 开关。强度可从 100% 开始调整。

点击引用或目录可前往 PDF 指定的位置。「返回原处」或浏览器后退恢复原来的页码、缩放和滚动位置。论文里的网页和 DOI 在新标签页打开，关闭后即可继续阅读。改变缩放或窗口宽度时会对准原段落。从扩展图标打开的 PDF 可以刷新续读，需要保留原 PDF 标签页。

点「查找」或按 Ctrl+F（Mac 用 ⌘F）搜索全书。Enter 查找下一处，Shift+Enter 查找上一处，到书末或书首会循环。Esc 关闭查找并留在当前命中处。要回到查找前的段落，点一次「返回原处」。

先导出一页，或取消正在制作的副本

在 Windows 工具的「导出页码」输入 1，先试做一页。导出中点「取消导出」，当前处理步骤结束后停止。原文件和已有副本会保留，可以调整范围再试。

在 WPS / Acrobat / Foxit / PDF-XChange 原页开关
  1. 在 Windows 制作工具中选择原始 PDF，选择「可切换版」。
  2. 保存成不同文件名，再用你的 PDF 阅读器打开副本。
  3. 在「图层 / Layers」面板开关「仿生阅读 · Bionic Reading」。图层默认关闭。

WPS：左侧「图层」图标 → 眼睛开关。PDF-XChange：Ctrl+L 打开图层 → 点击灯泡。

Acrobat：菜单 → 视图 → 显示/隐藏 → 侧面板 → 图层。Foxit：在左侧导航栏空白处右键 → 图层，再勾选该图层。不同版本菜单名称可能不同。找不到图层入口时可改用普通仿生版。

Preview / SumatraPDF / 手机等阅读器

在 Windows 工具选择「普通仿生版」，生成后直接打开。该副本的加粗始终显示；切回原始效果请打开原文件。

支持哪些语言？如何配置？

英语、法语、德语、西班牙语、葡萄牙语、意大利语、荷兰语、波兰语、土耳其语、越南语、俄语、乌克兰语、希腊语。

浏览器阅读混合语言文档时可选「词语前半部分」。在 Windows 工具制作副本时，自动和英语对纯英文字母词应用参考规则。选择其他语言时，按完整字素加粗前半词。手动选择还会设置副本的文档语言，自动模式沿用原文件的语言标记。重音和连字按完整字素或原始字形处理。

双页讲义、扫描页或乱码怎么办？

双页讲义左右两半合计一页。制作工具的「导出页码」可填 1-3,7,5-4，留空导出整本。完成后可查看未加粗的副本页码。讲义自带的翻页按钮也能在阅读页使用。

若正文无法选中，或只能选中标题、页码和零散的词，在 Windows 制作工具中勾选「扫描页本地 OCR」，选择文档语言并生成「可切换版」。先装好本机 Tesseract 5 和相应语言包。打开副本，点「查找」输入正文中的一句话。用「原始／仿生」切换时，识别出的文字始终可以搜索和复制。特殊字体和竖排文字可能保持原样。若出现乱码，先对照源 PDF。
