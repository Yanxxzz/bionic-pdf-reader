# 13 种语言的支持范围

本版支持英语 en、法语 fr、德语 de、西班牙语 es、葡萄牙语 pt、意大利语 it、荷兰语 nl、波兰语 pl、土耳其语 tr、越南语 vi、俄语 ru、乌克兰语 uk、希腊语 el。浏览器与 Windows 工具列出全部选项；命令行通过 `--language` 选择。

## 推荐设置

- 英语：文档语言选英语，先试「参考项目规则」，强度 100%。
- 其他 12 种语言：明确选择对应语言，使用「词语前半部分」。
- 多语言混排：可用自动分词与「词语前半部分」，并抽查自己的文档。

浏览器选择参考规则时，英语和自动模式会对纯英文字母词使用英语常用词和长度规则。选择其他语言时使用前半词规则。

桌面制作工具在自动和英语模式下使用同样的规则。例如 `the readers` 显示为 **t**he **read**ers，带重音的 `école` 显示为 **éco**le。显式选择其他 12 种语言时，所有可加粗的词都使用前半词规则。自动模式保留原 PDF 的语言标记，手动选择则写入所选语言。

浏览器使用 Intl.Segmenter；制作器使用 Unicode 字符类别。字素包括字母及其组合重音，不会只强调重音的一部分。PDF 字体中的连字作为一个原始字形处理，强调边界可能覆盖整个连字；不会拆开重新排版。若 PDF 提供 ActualText，会用它辅助识别连字的原始文字。

## 实际验证

13 种语言都有原创 PDF 示例，覆盖拉丁、西里尔和希腊字母。另有真实浏览器打印的带标签 / 不带标签 PDF，覆盖连字、组合重音和分开的绘制片段。测试比较原始文字、复制顺序、图层开关及关闭后的原始像素。法语和越南语还包含分解形式的组合重音。测试记录见 [verification.md](verification.md)。

其他语言未做适配验收，不列为支持项；拉丁、西里尔、希腊字母之外的文字不作词首强调。短大写缩写、公式、URL、已有粗斜体、旋转文字和无法可靠映射的字形通常跳过。纯图片扫描件可在制作工具启用本地 OCR，并选择对应语言。字体未嵌入、特殊 CMap、竖排和嵌套表单可能减少可强调内容。

支持语言不代表验证了该语言的每一种字体和文档，也不代表证明了阅读速度或理解效果。
