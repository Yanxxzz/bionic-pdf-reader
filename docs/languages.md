# 多语言规则与限制

## 已有示例与 PDF 测试

- 拉丁字母：英语、法语、德语、西班牙语、葡萄牙语、意大利语、荷兰语、波兰语、土耳其语、越南语。
- 西里尔字母：俄语、乌克兰语。
- 希腊字母：希腊语。
- 试验性分词与 PDF 示例：中文、日文、韩文。

这些示例覆盖原文保留、切换与像素恢复，不代表每个语言的所有字体和文档都已验证，也不证明阅读效果。

## 试验性复杂文字

阿拉伯语、希伯来语、印地语已加入 Unicode 词界和完整字素测试。字形本身不会被拆开重排，但实际 PDF 的连字、逻辑／视觉顺序、Unicode 映射及复杂排版仍会影响词首识别。尚未完成这些语言真实文档的全面排版验收；不应将算法单测等同于完整语言支持。

## 如何分词

浏览器用 `Intl.Segmenter` 按文档语言分词与划分字素。Python 用 Unicode 字符类别、中文 jieba 和日文 TinySegmenter；韩文按空格内的词段处理。两个环境的中日文边界可能不同。日文不含假名的片段建议明确选择 `ja`。

选择英语时，「参考规则」对英文字母词使用常用词和长度规则；明确选择其他语言时使用词语前半部分。`auto` 用于自动分词，不是文档语言识别：其中未带重音的英文字母词仍沿用参考规则。也可直接选择「词语前半部分」统一处理。组合重音和字素簇保持完整。单字词通常不做强调，已经使用粗体／斜体的片段、公式与旋转文字通常跳过。

原始 PDF 如何分隔绘制片段也会影响词界。无法可靠识别的片段保留原样，尤其是 OCR、竖排与特殊编码。

## 新语言如何贡献

在 `examples/languages.json` 中加入原创短句和可再分发字体，增加词界与 PDF 显示测试。请分别检查重音、标点、混排、复制顺序、连字及开关恢复，不只检查“是否出现加粗”。
