# 使用说明

## Chrome 与 Edge

下载并解压 `bionic-pdf-chrome-edge-版本.zip`。Chrome 在 `chrome://extensions`、Edge 在 `edge://extensions` 中启用开发者模式，加载含 `manifest.json` 的文件夹。点击扩展图标，选择或拖入本地 PDF。

开发版还可以从正在看的 PDF 开始。打开在线 PDF 后，点扩展图标，原标签页会保留。扩展向原站点读取这份 PDF，使用浏览器允许的登录凭据。本地 PDF 需在扩展详情里启用「允许访问文件网址」。如果网站使用临时地址或登录已失效，可先从原标签页保存，再在阅读页点「打开 PDF」。普通网页上的扩展按钮打开选文件界面。

顶部切换原始／仿生；`Alt+B` 为快捷键。侧栏可调整文档语言、参考规则／前半词规则和加粗强度。支持目录、页码、缩放、文字选择和复制。设置与进度保存在当前浏览器本地。点击顶部「使用指南」可以随时查阅配置步骤。英语先试参考规则和 100% 强度；其他语言推荐前半词规则。

当前开发版在窄窗口中提供「阅读设置与目录」。点开后可使用同一组控件，点目录条目会收起面板并显示目标段落。

在项目阅读页点击正文引用或目录条目，会按 PDF 保存的坐标和缩放显示目标段落。仅指定页码的链接打开目标页。「返回原处」或浏览器后退会恢复点击时的页码、缩放和滚动位置。

开发版中，点击 PDF 自带的网页或 DOI 链接会在新标签页打开，关闭它即可继续读原段落。调节缩放、调整「适合宽度」的窗口，或重开同一份 PDF，都能接续页内位置。

从扩展图标打开时，`#page=N` 指向物理页码，`#nameddest=名称` 或 `#名称` 会按原书签指定的段落和缩放打开。之后刷新阅读页，从这个阅读标签页上次停留处继续。请保留原 PDF 标签页。如果它已关闭或换了文档，阅读器会提示重新选文件。用「打开 PDF」手动选入的文件，刷新后需再选一次。

点「查找」或按 Ctrl+F（Mac 用 ⌘F）搜索整份 PDF 的文字层。用「下一处」或 Enter 向后找，「上一处」或 Shift+Enter 向前找。命中会在原页高亮，显示该页的命中序号。到书首或书末会循环，Esc 关闭。首次查找按需逐页读取，重复查找会复用已读取的文字。图片中的字需要 OCR 文字层。

## Windows 制作工具

下载 `bionic-pdf-windows-x64-版本.zip`，完整解压后运行 `BionicPDF.exe`；无需安装 Python，也不修改 WPS 或其他阅读器的程序文件。窗口内「使用指南与配置说明」提供分步说明；压缩包中的 `使用指南.html` 可直接双击离线查看。

1. 选择原始 PDF。
2. 给阅读副本选择不同的文件名。
3. 可开关图层的阅读器选择「可切换版」；其他阅读器选择「普通仿生版」。
4. 选择文档语言。英语对纯英文字母词使用参考规则，其他 12 种语言使用前半词规则。自动模式也使用前半词规则，并保留原文档的语言标记。
5. 生成后查看「未加粗的页码」，再用平时的阅读器打开副本。清单按副本的物理页从 1 开始编号，列出整页没有加入词首笔画的页面。一张双页讲义算一页。若整份都无法加粗，工具会显示原因和涉及的页码。

桌面制作工具仅从未加密的 PDF 导出副本。已有数字签名的 PDF 会在处理页面前弹出提示。选择「否」可保留原件，点击「在浏览器中阅读」直接阅读。选择「是」会生成阅读副本，原签名在这份副本中失效。命令行需显式传入 `--allow-signature-loss` 才会继续。

若文档限制复制，浏览器阅读页会在复制正文时提示。

Windows 便携版和 Python 安装包的图形界面都可点击「在浏览器中阅读」。当前开发版会直接打开桌面工具里选好的原始 PDF。未选文件时，阅读页会显示文件选择入口。文件只经本机传递。使用同一浏览器重新打开同一份 PDF，可以接续页码和设置。默认地址为 `http://127.0.0.1:8765/reader.html`，端口占用时会使用临时地址，进度单独保存在该地址下。使用期间请保持制作工具开启。

通过 Python 的 `make_pdf(..., pages=[...])` 选页时，开发版会保留所选页的无障碍阅读顺序、替代文本和批注关联。遇到无法随页面完整迁移的标签会停止并提示导出整本。整本导出保留具有独立标签的嵌套 Form 对象，这些对象内部的文字保持原样。

## WPS 与图层阅读器

WPS 左侧点叠纸形的「图层」图标，点 `仿生阅读 · Bionic Reading` 左侧的眼睛。Acrobat、Foxit 与 PDF-XChange 也使用各自的 Layers／图层面板。PDF-XChange 可以按 `Ctrl+L` 打开图层，点击图层左侧灯泡。

图层默认关闭。开关作用于整本副本，页面位置和缩放保持不变。阅读器是否在关闭后记住图层状态，由阅读器管理。找不到图层入口时，可以改用普通仿生版。

Acrobat Reader 的新版界面可点右侧叠纸形的「图层」图标，再点 `仿生阅读 · Bionic Reading` 左边的小方框。也可从「视图 → 显示/隐藏 → 侧面板 → 图层」打开面板。[Adobe 官方说明](https://helpx.adobe.com/acrobat/desktop/edit-documents/pdf-layers/manage-layers.html)

Foxit 可在左侧导航栏的空白处右键打开 Layers，然后勾选图层。[Foxit Windows 手册，第 95 页](https://cdn01.foxitsoftware.com/pub/foxit/manual/reader/en_us/foxit-pdf-reader-user-manual-2026.1.1.pdf)

## Safari、Firefox 与其他浏览器

推荐使用 Windows 程序打开的本地阅读页，或在源码目录运行：

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory extension
```

打开 `http://127.0.0.1:8765/reader.html`。在 Safari 点「打开 PDF」，从 macOS 文件窗口选中本地 PDF。在阅读页按 `Option+B` 或点「仿生」开启词首加粗，点「原始」即可在同一页恢复。[兼容性说明](compatibility.md)

Firefox 临时扩展：解压 `bionic-pdf-firefox-temporary-版本.zip`，进入 `about:debugging#/runtime/this-firefox`，选择「临时载入附加组件」，打开解压目录中的 `manifest.json`。这个包供开发测试，重启 Firefox 后会移除；当前没有 Mozilla 签名，不是可永久安装的商店版本。

## 常见问题

- **没有加粗**：可能是扫描图片、字体未嵌入、特殊编码、原有粗斜体、竖排或文本被拆成过短片段。当前没有内置 OCR。
- **部分文字保持原样**：程序会跳过无法可靠处理的字体、公式、旋转标签和特殊文字片段，保留原页。
- **复制出现重复文字吗**：生成的加粗层使用字形轮廓，不加入第二份正文；测试会比较开关前后的原始文字。
- **是否提高阅读速度**：这是可选的视觉呈现方式。是否适合你需要自行比较，项目没有提高阅读速度或理解率的效果保证。
- **为什么原阅读器仍提示云同步**：本工具不上传 PDF；第三方阅读器的云同步由该阅读器的设置管理。

## 更新已有安装

Chrome / Edge：将新 ZIP 解压到固定文件夹，在扩展管理页重新加载该文件夹。保留原扩展时可更新同一目录并点「重新加载」。Windows：关闭旧工具，完整解压新包，再运行新 BionicPDF.exe。新包不会修改已经生成的阅读副本；需要新算法时，从原始 PDF 重新制作一份。

如果曾选择本版范围外的试验语言，浏览器会恢复到自动分词。请选择这 13 种语言之一。原始 PDF 和旧版阅读副本可以继续保留。
