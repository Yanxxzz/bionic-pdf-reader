# 使用说明

## Chrome 与 Edge

下载并解压 `bionic-pdf-chrome-edge-版本.zip`。Chrome 在 `chrome://extensions`、Edge 在 `edge://extensions` 中启用开发者模式，加载含 `manifest.json` 的文件夹。点击扩展图标，选择或拖入本地 PDF。

也可以从正在看的 PDF 开始。打开在线 PDF 后，点扩展图标，原标签页会保留。扩展向原站点读取这份 PDF，使用浏览器允许的登录凭据。本地 PDF 需在扩展详情里启用「允许访问文件网址」。如果网站使用临时地址或登录已失效，可先从原标签页保存，再在阅读页点「打开 PDF」。普通网页上的扩展按钮打开选文件界面。

顶部切换原始／仿生；`Alt+B` 为快捷键。侧栏可调整文档语言、参考规则／前半词规则和加粗强度。支持目录、页码、缩放、文字选择和复制。设置与进度保存在当前浏览器本地。点击顶部「使用指南」可以随时查阅配置步骤。英语先试参考规则和 100% 强度；其他语言推荐前半词规则。

窄窗口中可展开「阅读设置与目录」。点开后可使用同一组控件，点目录条目会收起面板并显示目标段落。

在项目阅读页点击正文引用或目录条目，会按 PDF 保存的坐标和缩放显示目标段落。讲义自带的首页、上页、下页和末页按钮沿用当前缩放。「返回原处」或浏览器后退会恢复点击时的页码、缩放和滚动位置。

点击 PDF 自带的网页或 DOI 链接会在新标签页打开，关闭它即可继续读原段落。文件改名仍可续读，同一网址替换了内容会单独记录进度。远程 PDF 可以先读首页，完整下载后再恢复书签。如果已经翻页，阅读器会保留你当前的位置。

从扩展图标打开时，`#page=N` 指向物理页码，`#nameddest=名称` 或 `#名称` 会按原书签指定的段落和缩放打开。之后刷新阅读页，从这个阅读标签页上次停留处继续。请保留原 PDF 标签页。如果它已关闭或换了文档，阅读器会提示重新选文件。手动选入或拖入的 PDF 在刷新时通过本机浏览器内存短暂交接，无需重新选文件。浏览器回收这份临时数据时，请再选原件以恢复阅读位置。加密文件仍需输入密码。

点「查找」或按 Ctrl+F（Mac 用 ⌘F）搜索整份 PDF 的文字层。用「下一处」或 Enter 向后找，「上一处」或 Shift+Enter 向前找。命中会在原页高亮，显示该页的命中序号。到书首或书末会循环，Esc 关闭。首次查找按需逐页读取，重复查找会复用已读取的文字。图片中的字需要 OCR 文字层。

## Windows 制作工具

下载 `bionic-pdf-windows-x64-版本.zip`，完整解压后运行 `BionicPDF.exe`；无需安装 Python，也不修改 WPS 或其他阅读器的程序文件。窗口内「使用指南与配置说明」提供分步说明；压缩包中的 `使用指南.html` 可直接双击离线查看。

1. 选择原始 PDF。
2. 给阅读副本选择不同的文件名。
3. 可开关图层的阅读器选择「可切换版」；其他阅读器选择「普通仿生版」。
4. 选择文档语言。自动和英语对纯英文字母词使用参考规则，其他词按完整字素加粗前半词。显式选择其他 12 种语言时统一使用前半词规则。自动模式保留原 PDF 的语言标记。
5. 生成后查看「未加粗的页码」，再用平时的阅读器打开副本。清单按副本的物理页从 1 开始编号，列出整页没有加入词首笔画的页面。一张双页讲义算一页。若整份都无法加粗，工具会显示原因和涉及的页码。

桌面制作工具仅从未加密的 PDF 导出副本。已有数字签名的 PDF 会在处理页面前弹出提示。选择「否」可保留原件，点击「在浏览器中阅读」直接阅读。选择「是」会生成阅读副本，原签名在这份副本中失效。命令行需显式传入 `--allow-signature-loss` 才会继续。

若文档限制复制，浏览器阅读页会在复制正文时提示。

Windows 便携版和 Python 安装包的图形界面都可点击「在浏览器中阅读」。会直接打开桌面工具里选好的原始 PDF。未选文件时，阅读页会显示文件选择入口。文件只经本机传递。使用同一浏览器重新打开同一份 PDF，可以接续页码和设置。默认地址为 `http://127.0.0.1:8765/reader.html`，端口占用时会使用临时地址，进度单独保存在该地址下。使用期间请保持制作工具开启。

「导出页码」留空可导出整本。输入 `1-3,7,5-4` 会依次得到第 1、2、3、7、5、4 页，也可以重复选页。页码从原 PDF 的第一页算起。命令行使用 `--pages "1-3,7,5-4"`，Python 的 `make_pdf(..., pages=...)` 同时接受这个字符串和整数序列。选页会保留可映射的阅读顺序、替代文本和批注关联。遇到无法安全分开的结构会说明原因，已有目标文件会保留。

## 扫描件本地 OCR

1. 在本机安装 Tesseract 5 和文档对应的语言包，例如英语用 `eng`。在终端运行 `tesseract --list-langs` 可查看已安装模型。Windows 常规安装目录也能被制作工具自动识别。Windows 便携版自带图像处理组件。使用 Python 源码时运行 `python -m pip install ".[ocr]"`。[13 种语言与模型名](languages.md#ocr-语言模型) · [Tesseract 安装说明](https://tesseract-ocr.github.io/tessdoc/Installation.html) · [官方语言模型](https://github.com/tesseract-ocr/tessdata_fast)
2. 在制作工具中选择原 PDF、文档语言和「可切换版」，勾选「扫描页本地 OCR」。在命令行可运行 `bionic-pdf scan.pdf reading.pdf --ocr --language en --mode switchable`。也可以用 `--pages` 先试读一页。自动模式优先使用 PDF 的语言标记，无法识别语言时使用英语。
3. 打开副本，在浏览器的「原始／仿生」按钮或桌面阅读器的图层面板切换。词首沿用扫描图中的笔迹颜色。纯图片页会获得可搜索、复制的文字，已有部分隐藏文字的页面会补上识别出的缺词。识别与生成都在本机完成。

清晰、横排、字迹与底色对比分明的扫描最适合，包括黑底白字和浅底彩色字。背景复杂或对比度过低时，字迹可保留原样。纯数字页也可生成可搜索的副本，并列在未加粗页码中。偏斜或模糊的字可能识别有误。批注覆盖的区域和使用原有可选图层的扫描内容会跳过。若一页已有可见 PDF 文字，程序沿用原字形处理。缺少引擎或语言模型时会在替换目标文件前报错。

## WPS 与图层阅读器

WPS 左侧点叠纸形的「图层」图标，点 `仿生阅读 · Bionic Reading` 左侧的眼睛。Acrobat、Foxit 与 PDF-XChange 也使用各自的 Layers／图层面板。PDF-XChange 可以按 `Ctrl+L` 打开图层，点击图层左侧灯泡。

图层默认关闭。开关作用于整本副本，页面位置和缩放保持不变。阅读器是否在关闭后记住图层状态，由阅读器管理。找不到图层入口时，可以改用普通仿生版。

Acrobat Reader 的新版界面可点右侧叠纸形的「图层」图标，再点 `仿生阅读 · Bionic Reading` 左边的小方框。也可从「视图 → 显示/隐藏 → 侧面板 → 图层」打开面板。[Adobe 官方说明](https://helpx.adobe.com/acrobat/desktop/edit-documents/pdf-layers/manage-layers.html)

Foxit 可在左侧导航栏的空白处右键打开 Layers，然后勾选图层。[Foxit Windows 手册，第 95 页](https://cdn01.foxitsoftware.com/pub/foxit/manual/reader/en_us/foxit-pdf-reader-user-manual-2026.1.1.pdf)

## Safari、Firefox 与其他浏览器

推荐使用 Windows 程序打开的本地阅读页，或在源码目录运行：

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory extension
```

打开 `http://127.0.0.1:8765/reader.html`。在 Safari 点「打开 PDF」，从 macOS 文件窗口选中本地 PDF。在阅读页按 `Option+B` 或点「仿生」开启词首加粗，点「原始」即可在同一页恢复。[兼容性说明](compatibility.md)

**Firefox 直接读 PDF**。用桌面制作工具导出「可切换版」，然后用 Firefox 打开该 PDF。在 Firefox 159 中，点左上方「管理页面 / Manage pages」，从「视图 / Views」选择「图层 / Layers」，勾选或取消 `仿生阅读 · Bionic Reading`。这条路径使用浏览器自带的阅读器，重启后仍可直接打开文件。

**Firefox 阅读原件**。需要直接调节强度或语言时，可以把项目的本地阅读页加入书签。解压 `bionic-pdf-web-reader-版本.zip` 到固定文件夹，在该文件夹运行 `python -m http.server 8765 --bind 127.0.0.1`，然后在 Firefox 打开 `http://127.0.0.1:8765/reader.html` 并按 Ctrl+D（macOS 用 ⌘D）。重启 Firefox 后，在本地服务运行时从书签进入，重新选择同一份 PDF 即可接续进度。Windows 制作工具打开的本地阅读页也可以收藏，使用时保持工具开启并使用同一端口。

**Firefox 临时扩展**适合测试。解压 `bionic-pdf-firefox-temporary-版本.zip`，进入 `about:debugging#/runtime/this-firefox`，选择「临时载入附加组件」，打开解压目录中的 `manifest.json`。Firefox 重启后会移除临时扩展。长期安装需要 Mozilla 签名的 XPI。[开发者签名步骤](development.md#firefox-签名)

## 常见问题

- **没有加粗**。纯图片扫描件可启用本地 OCR。未嵌入字体、特殊编码、原有粗斜体、竖排或过短的文字片段可能保持原样。
- **部分文字保持原样**：程序会跳过无法可靠处理的字体、公式、旋转标签和特殊文字片段，保留原页。
- **复制出现重复文字吗**：生成的加粗层使用字形轮廓，不加入第二份正文；测试会比较开关前后的原始文字。
- **是否提高阅读速度**：这是可选的视觉呈现方式。是否适合你需要自行比较，项目没有提高阅读速度或理解率的效果保证。
- **为什么原阅读器仍提示云同步**：本工具不上传 PDF；第三方阅读器的云同步由该阅读器的设置管理。

## 更新已有安装

从 0.5.0 升级时，原标签页能交回的本地文件会沿用该标签页的进度。旧标签页已关闭、只剩旧版指纹的文档，首次打开时需要重新定位一次。

Chrome / Edge：将新 ZIP 解压到固定文件夹，在扩展管理页重新加载该文件夹。保留原扩展时可更新同一目录并点「重新加载」。Windows：关闭旧工具，完整解压新包，再运行新 BionicPDF.exe。新包不会修改已经生成的阅读副本；需要新算法时，从原始 PDF 重新制作一份。

如果曾选择本版范围外的试验语言，浏览器会恢复到自动分词。请选择这 13 种语言之一。原始 PDF 和旧版阅读副本可以继续保留。
